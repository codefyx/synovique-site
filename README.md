# SYNOVIQUE deployable website

Static responsive website. No build step, package manager or server required.

## Deploy
Upload the contents of this folder to Netlify (manual deploy), Cloudflare Pages (Direct Upload), GitHub Pages, or your web host's public web root. Keep `index.html`, `styles.css`, `script.js` and the `assets` folder together.

## Before launch: contact email
In `script.js`, replace `hello@synovique.com` in `CONTACT_EMAIL` with your official enquiry inbox. The contact form uses a `mailto:` link: it opens the visitor's email application with a prefilled enquiry; it does not independently transmit or store form submissions. For server-side submissions, connect Netlify Forms, Formspree or your own backend.

## Brand palette
Midnight navy #101D32 · Champagne #B49A72 · Warm ivory #EAE7DF · Executive teal #477F82 · Slate #596579 · Silver mist #D6DCE3.

The emblem and favicon are included as scalable SVG. Google Fonts are used with system fallbacks. No external stock imagery is required.

## Launch checklist
- Set the correct contact email.
- Connect your domain and enable HTTPS.
- Add a real privacy policy/terms if you add analytics, cookies or data collection.
- Publish only substantiated credentials, client stories and outcome claims.
- Complete trademark clearance for the name and logo; this package is not legal clearance.
